## REMOVED Requirements

### Requirement: User can view tasks in Kanban board format
**Reason**: Feature deemed unnecessary by users and clutters the interface.
**Migration**: Users can view and manage tasks exclusively through the List view in Task Management.

### Requirement: User can create custom board columns
**Reason**: Kanban board is removed.
**Migration**: None.

### Requirement: User can drag and drop tasks between columns
**Reason**: Kanban board is removed.
**Migration**: Use status dropdowns in the task list to change task state.

### Requirement: User can reorder tasks within columns
**Reason**: Kanban board is removed.
**Migration**: Task list sorting by due date or priority.

### Requirement: Task card displays essential information
**Reason**: Kanban board is removed.
**Migration**: Task list displays all essential information.

### Requirement: User can click task card to view/edit details
**Reason**: Kanban board is removed.
**Migration**: Click task row in the task list.

### Requirement: User can filter Kanban board by subject or priority
**Reason**: Kanban board is removed.
**Migration**: Use filters on the task list view.
