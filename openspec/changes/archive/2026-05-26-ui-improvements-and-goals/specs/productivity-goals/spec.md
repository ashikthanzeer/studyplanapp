## ADDED Requirements

### Requirement: User can set and update productivity goals
The system SHALL allow users to define target study hours for different periods (e.g., daily, weekly) and update them as needed.

#### Scenario: Update weekly study goal
- **WHEN** the user navigates to the goals section and inputs a new target of 15 hours for the week
- **THEN** the system SHALL save the updated goal and reflect this target in the dashboard progress indicators
